原作 `gensaku.txt`（全4021行・1年〜3年一学期）を読了し、ゲームに必要な画像を洗い出しました。
このフォルダにある **同名の `.jpg` で上書きするだけで差し替え完了** です（コード変更不要）。

## 差し替えルール

- ファイル名・拡張子は変えない（`.jpg` のまま。`.png` 等に変えるとimportエラーになります）
- 推奨サイズ：人物・部員＝ **1200×1600（3:4）**／背景＝ **1792×1008（16:9）**
  - 既存の本番画（`ryoma.jpg` 等＝1200×1600、`title.jpg` 等＝1792×1008）に合わせています
- 表示は `object-cover`（中央基準トリミング）なので、顔・主役は中央寄せで
- jpgのため透過不可。丸アイコン表示（チャット等）では四隅が切れます
- 仮画像は白地＋グレーラベル。本番画に置き換わると自動でゲーム内に反映されます

## 画像化していないもの（絵文字表示のまま）

- アイテム・装備（30種：ホットコーンスープ、封印の刻印、地形図…）

- 敵キャラ（各章ボス・対抗戦12校・全国模試）

いずれも絵文字で成立しているため対象外。必要になったら `item-{id}.jpg`／`facility-{id}.jpg` 等の命名で追加します。敵は100種超のため、出すなら章ボス・学校ボスのみ等に要相談。
